# Agent instructions

## Screenshots in pull request summaries

Every pull request that changes the website's presentation must include at least one screenshot of the finished result, embedded directly in the PR summary (description). This includes changes to layout, styling, visible text, images, or other UI.

Capture the screenshot after the final changes and show the affected area clearly. Use Markdown image syntax with a URL that GitHub can render. Screenshots shown only in chat, linked as files, or added in PR comments do not satisfy this requirement.

Screenshots are not required for documentation-only changes or other changes that do not affect the website's presentation.
